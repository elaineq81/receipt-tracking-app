ReceiptSure helps users scan, organize, and export receipt and expense records. The current version processes receipt text on the device and stores receipt images and expense details in the app’s private local storage.

## Data handling

ReceiptSure does not transmit receipt images, extracted text, expense data, or identifiers to the developer. It does not include accounts, advertising, analytics, tracking, or third-party data-collection SDKs. Data leaves the app only when the user deliberately exports, backs up, or shares a file using Apple’s system interfaces; the privacy practices of the selected destination then apply. Optional secure archives are encrypted locally with a password-derived key, and the password is not stored by ReceiptSure.

## Camera and photos

Camera access is requested only when the user starts a receipt scan. Apple VisionKit is used to detect and crop the document. Image and PDF imports use Apple’s system pickers, which provide only the files selected by the user.

## Retention and deletion

Records remain on the user’s device until the user deletes them or removes the app. Files that the user exports or backs up remain wherever the user chose to save or share them. Device backups may be handled by the user’s Apple and device settings.
